# Phần mềm sử dụng

Repository không chứa bộ cài vì dung lượng lớn. Các phần mềm đều miễn phí, tải tại trang chính thức của Microsoft.

| Phần mềm | Phiên bản dùng khi làm đồ án | Nơi tải |
|---|---|---|
| Visual Studio Community | 2026 (dùng được bản 2022) | https://visualstudio.microsoft.com/ |
| SQL Server | 2025 (dùng được bản Express từ 2019 trở lên) | https://www.microsoft.com/sql-server/sql-server-downloads |
| SQL Server Management Studio | 22 | https://learn.microsoft.com/sql/ssms/download-sql-server-management-studio-ssms |
| .NET Framework | 4.8 (Developer Pack / targeting pack) | Cài kèm khi chọn trong Visual Studio Installer |

**Khi cài Visual Studio:**
- Tab *Workloads*: chọn **ASP.NET and web development**.
- Tab *Individual components*: chọn **.NET Framework 4.8 targeting pack** và **.NET Framework project and item templates**.

**Phông chữ:** Be Vietnam Pro (giấy phép SIL OFL) đã đóng gói sẵn trong `src/WebLinhKien/App_Themes/LinhKien/fonts`, không cần cài thêm.
